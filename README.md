# カラードロップ

外部ライブラリ・素材を使わない、一人用のブラウザ落ち物パズルです。

## 公開版

[カラードロップをブラウザで遊ぶ](https://tetu5473.github.io/color-drop/)

## 起動とテスト

このフォルダで `python3 -m http.server 8767 --bind 127.0.0.1` を実行し、`http://localhost:8767/` を開きます。ファイルを直接開くと ES Modules の読み込みが制限されるため、HTTP サーバーを利用します。

テストは `node --test *.test.mjs` で実行します。追加パッケージは不要です。

## ルール・操作

- 6列・表示12段と非表示1段。四色のブロックが二個一組で落下します。
- 同色4個以上が上下左右につながると消去し、重力で再びつながれば連鎖します。
- 得点は各消去で「消した個数 × 10 × 連鎖数の二乗」。即落下の加点はありません。
- 出現位置が埋まるか、消去解決後に非表示行へブロックが残ると終了します。
- ← →：移動、↑ / X：右回転、Z：左回転、↓：一段落下、Space：即落下、P：停止・再開。
- 画面ボタンでも全操作ができます。左右と下は長押し対応です。
- 「最初から」はゲーム内で確認し、確定すると盤面と得点を初期化します。
- 音楽は独自の16小節「キャンディ・ステップ」をWeb Audioで演奏します。音ボタンでBGMと効果音をまとめて切り替え、一時停止や画面離脱時は音も止まります。
- 四色のキャラクターは、このゲーム用に描いたSVGです。既存ゲームの画像・音源・楽譜は取り込んでいません。
- 保存・通信・公開機能はありません。再読み込みするとゲームは初期化されます。

## 選曲・消去音・掛け声（2026-09-09）

操作ボタン下の「音楽・声」で4曲を選べます。「BGMなし」は効果音と声を残し、「声OFF」は声だけを止めます。右上の音ボタンはすべての音を止めます。「消去音と声を試す」は開始前・一時停止中でも試聴できます。

- キャンディ・ステップ：132 BPM、弾む三角波。
- ひだまりピクニック：96 BPM、ゆったりした正弦波。
- ソーダ・スパーク：156 BPM、軽快な矩形波。
- 星くずワルツ：116 BPM、三拍子。

消去時は泡のはじける音と連鎖音を重ね、1～5連鎖で「ぽんっ！」「つながった！」「いい感じ！」「すごい、すごい！」「やったー！」と声が変わります。掛け声のWAVはMacのKyoko音声・速度250でローカル生成し、22,050 Hzの16-bit PCMへ変換しています。既存ゲームの声や音源は使用していません。

自動テスト34件合格。4曲のループ、消去の発音、重複・遅延発声の抑制、停止・ミュート、音声波形を検証。ブラウザで選曲・試聴・声OFF・開始と一時停止を確認し、掛け声の再生完了とエラーなしを確認しました。実スピーカーでの聴感とスマートフォン実機は未確認です。
